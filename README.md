A 4 KB Python chess engine: 0x88 alpha-beta with null-move pruning, late-move reductions, transposition table and quiescence search. Practice trial-0 Elo 1131 (4W/1D/11L) at a fixed 25,000 nodes/move. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
